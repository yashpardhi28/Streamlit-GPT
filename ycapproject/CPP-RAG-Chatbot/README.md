# C++ RAG Chatbot

A Retrieval-Augmented Generation (RAG) chatbot that answers C++ programming questions using a local knowledge base.

## Features

- Reads C++ text data
- Splits documents into chunks
- Creates FAISS vector database
- Retrieves relevant information
- Answers C++ questions

## Technologies

- Python
- LangChain
- FAISS
- HuggingFace Embeddings

## Run

```bash
pip install -r requirements.txt
jupyter notebook
```
