# Streamlit GPT Chatbot

A simple AI chatbot built using Streamlit, LangChain, and Ollama.

## Features

- Chat interface using Streamlit
- Uses LangChain
- Uses Ollama (Gemma 2B)
- Simple and clean UI

## Technologies Used

- Python
- Streamlit
- LangChain
- Ollama
- Gemma 2B

## Installation

```bash
pip install -r requirements.txt
streamlit run app.py
```
