# ESP32 PDF RAG Chatbot

A chatbot that answers questions from the ESP32 Datasheet using Retrieval-Augmented Generation (RAG).

## Features

- Reads ESP32 PDF
- Creates embeddings
- Stores vectors using FAISS
- Answers questions from the datasheet

## Technologies

- Python
- LangChain
- FAISS
- HuggingFace
- PyPDF

## Run

```bash
pip install -r requirements.txt
jupyter notebook
```
